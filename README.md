Code in this repository is made for running analyses on neural data reported in Bakhurin et al. 

Basics to load the data:
Data is stored in *.NEX5 files, one for each recording. Each animal contains a set of these files. 
The files have spike data, timestamp events, continuous kinematics and ethogram data, and waveforms for each spike.

Two sets of excel files contain lists of neural data from each animal and the cell type categorizations.

Several functions read from these lists and work to isolate relevant neural and behavioral data from the NEX5 files.
